# Support

## Where to get help

### Documentation

Read the documentation in the [`Documentation`](Documentation/Index.rst)
folder, in particular *Troubleshooting*. Product information is on the
[Context Reporter website](https://typo3.priebera.sk/context-reporter).

### Bugs and feature requests

Open a [GitHub issue](https://github.com/priebera1/typo3-context-reporter/issues/new/choose)
using the appropriate template. Context Reporter is deliberately not a ticket
system; feature requests for boards, assignments, SLAs or native connectors
to individual ticket systems are out of scope.

### Security vulnerabilities

Do not report security issues publicly. Use
[GitHub private vulnerability reporting](https://github.com/priebera1/typo3-context-reporter/security/advisories/new)
or email **support@priebera.sk**. See [SECURITY.md](SECURITY.md).

## What not to share publicly

Reports contain page titles, record labels, file names and backend URLs. Do
not post real reports, screenshots with personal data, webhook URLs or
secrets, email addresses or client domain names in GitHub issues.
